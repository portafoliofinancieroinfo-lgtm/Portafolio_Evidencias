# 🎓 Estudios — Formación y práctica en QA Testing

Formación técnica complementaria a mi carrera de Contaduría Pública, con
énfasis en **aseguramiento de calidad de software (QA)**.

## Bootcamp QA Engineer — TripleTen (2025–2026)

Programa intensivo de QA Testing con proyectos prácticos sobre aplicaciones
web, móviles y APIs. Todo el código y la documentación están publicados en el
repositorio [**Bootcamp-QA**](https://github.com/portafoliofinancieroinfo-lgtm/Bootcamp-QA):

| # | Proyecto | Enfoque |
|---|---|---|
| 01 | Automatización Selenium WebDriver | Fundamentos de automatización web: localizadores, esperas explícitas, interacción con el DOM |
| 02 | Patrón Page Object Model | Suites mantenibles separando páginas y pruebas |
| 03 | Pruebas de API con Python | Casos positivos/negativos con `requests` + `pytest` |
| 04 | Proyecto final: Urban Grocers QA | Suite de API con **3 bugs reales encontrados**, incluido un Error 500 crítico |
| 05 | Documentación de pruebas manuales | 6 proyectos de QA manual (web, cross-browser, móvil Android, API Postman) con **30+ bugs reportados en Jira** |

### Habilidades desarrolladas

- **Diseño de pruebas:** clases de equivalencia, valores límite, tablas de decisión, mapas mentales, diagramas de flujo.
- **Ejecución:** pruebas funcionales de UI, cross-browser (Chrome/Firefox/Opera), móviles (emuladores Android Studio, ADB) y de API (Postman, Python).
- **Reporte de defectos:** bug reports con pasos de reproducción, severidad y evidencia, gestionados en **Jira**.
- **Automatización:** Selenium WebDriver, patrón Page Object Model, `pytest`.
